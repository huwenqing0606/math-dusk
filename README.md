# 数学的黄昏 (The Dusk of Mathematics)

**Version:** v21 — 人生选择树 / 审查修改版

一款以数学学习、学术生涯和人生抉择为主题的中文互动叙事游戏。玩家可以在浏览器中直接游玩，探索不同选择所带来的命运与成就。

## 在线游玩

GitHub Pages: https://huwenqing0606.github.io/math-dusk/

无需安装。游戏在浏览器运行，进度保存在本地浏览器中；请自行备份重要存档。

## 发布与更新

本仓库使用 GitHub Pages 托管静态网页。

- 入口：`index.html`
- 部署：仓库 **Settings → Pages → Deploy from a branch → main → /(root)**
- 后续更新：将新版本游戏替换为 `index.html` 并提交；Pages 会重新部署。

`index.html` 是经确认的 v21 游戏原文件，未重新压缩或编辑插画、文字、游戏逻辑。审查资料及开发中的草稿不包含在本发布包中。
